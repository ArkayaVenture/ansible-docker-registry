# CLAUDE.md

Standing instructions for Claude Code and other autonomous agents working in this repository.

## Mission brief (applies across all ArkayaVenture, BotGeniuses, ark-us-platform and soumentrivedi repositories)

Read `docs/missions/GO2LEARNAI_FLIGHT_MISSION_BRIEF.md` before starting substantial work. It defines:

- the orchestration model (Mission Orchestrator → specialist workstreams → independent verifier → integration agent → readiness report)
- the ten workstreams (Cloudflare/India access, SCORM architecture and sample content, Jev AI and Hermes Agent POCs, Slack agent app and integration, Soul-Verse and cloud cost, shared memory, token/model/infra cost)
- the token-optimisation (M0–M8 memory tiers), second-brain write, model-routing and context-efficiency policies
- the autonomous access policy and the human approval gates (production deploys, destructive cloud changes, resource deletion, permission escalation, external communication, credentials, production users, billing, new public endpoints, weakening security)
- the shared agent output format and the Definition of Done: working implementation, validated artefact, measured analysis, or documented decision with evidence. Research alone is never DONE.

## Repository-specific guidance

Follow the conventions documented in this repository's README and existing docs. Keep changes minimal, tested where tooling exists, and delivered as pull requests.
